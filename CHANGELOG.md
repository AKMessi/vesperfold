# Changelog

## 1.0.0 — 2026-10-02

- First release of the Vesperfold local-first text encryption app.
- Added the versioned `vf1.` envelope format with a fixed Argon2id profile and XChaCha20-Poly1305 authentication.
- Added random ten-digit key generation, package sharing, decryption, and static-site deployment workflows.
- Documented security limits, including offline guessing, missing sender identity, and the absence of an independent security audit.
- Added a short demo video and clarified that stronger passphrases require a different tool.
- Declared the MIT license in package metadata and named the project copyright holder.
